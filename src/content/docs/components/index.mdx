## Available in the package

`@loquix/core` also exports the following component families. They are available in version 0.4.1, while full reference pages are scheduled after the first documentation release:

- **Actions:** Action Button, Action Copy, Action Edit, Action Feedback
- **Attachments:** Attachment Panel
- **Reasoning and trust:** Tool Call, Tool Call List, Citation Popover, Source List, Confidence Indicator, Uncertainty Marker, Disclosure Badge, Caveat Notice, Disagreement Marker
- **Feedback:** Feedback Form, Correction Input
- **Search:** Search Input, Search Sources, Search Result, Search Results, Search Answer, Search Footer, Search Dialog, Search Panel
- **Configuration:** Dropdown Select, Parameter Panel, Filter Bar
- **Templates and guidance:** Template Card, Template Picker, Example Gallery, Nudge Banner
- **Infrastructure:** Scroll Anchor

<Aside type="note" title="Coverage, not stability">
	“Documented” describes reference coverage on this website. It is not a separate stability promise. Use the installed package version and its release notes as the source of truth for API compatibility.
</Aside>
